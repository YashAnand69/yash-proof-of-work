# Yash Anand — proof of work

An original static portfolio page for sharing selected, inspectable projects with prospective clients. No third-party artwork, tracking, backend, build step, or runtime secrets.

## Local preview

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. Deploy the directory as a static site on Vercel with `npx vercel --prod --yes` after connecting the account. The page intentionally distinguishes independent concepts and prototypes from client work.
